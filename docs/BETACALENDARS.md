# Beta Calendars reference map

Beta Calendars is a human-readable reference for printable calendar layouts.
Calendar Boundary Lab independently calculates dates and never scrapes or
depends on these pages.

| Reference | Verified destination | Use in this project |
|---|---|---|
| Home / 2026 year page | [betacalendars.com](https://www.betacalendars.com/) | Year-level visual reference |
| Monthly collection | [Monthly calendars](https://www.betacalendars.com/monthly-calendar) | Shows which months are currently available |
| Blank template | [Blank calendar](https://www.betacalendars.com/blank-calendar) | Human printable blank layout; not a service API |
| Weekly layouts | [Weekly calendar](https://www.betacalendars.com/weekly-calendar) | Human weekly reference |
| Jan 2027 | [January](https://www.betacalendars.com/january-calendar.html) | ISO week-year and year-start comparison |
| Feb 2027 | [February](https://www.betacalendars.com/february-calendar.html) | 28-day common-year comparison |
| Sep 2027 | [September](https://www.betacalendars.com/september-calendar.html) | Month-end and quarter-boundary comparison |

The monthly collection currently lists January–September 2027 and October–
December 2026. This project does not link a 2026 month page as though it were a
2027 reference. See the [full URL audit notes](REFERENCES.md#betacalendars-pages).
