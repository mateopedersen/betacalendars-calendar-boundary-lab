# Blank and annual calendars

The Boundary Lab's `/v1/year/{year}/matrix` is an engineering matrix. It
contains each month’s start weekday, length, row counts, and ISO week spans. It
does not render a twelve-month poster, provide holidays, or create a blank
calendar template.

Beta Calendars publishes human-oriented print resources that are useful for
visual comparison:

- [Monthly calendar collection](https://www.betacalendars.com/monthly-calendar)
- [Blank calendar](https://www.betacalendars.com/blank-calendar)
- [Weekly calendars](https://www.betacalendars.com/weekly-calendar)
- [2026 calendar home](https://www.betacalendars.com/)

These are website pages, not endpoints of this Go service. As of this audit, the
site's monthly collection exposes January through September 2027 and October
through December 2026; no direct 2027 annual or last-quarter monthly page was
verified.
